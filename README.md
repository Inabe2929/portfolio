# イナベ ポートフォリオ

Excel・CSV作業の自動化や、小規模なWebサイト制作を承っています。

## 制作サンプル

### 1. 売上CSV 統合・集計レポート自動作成ツール（Python）
→ [csv-report-tool](./csv-report-tool/)

形式の違う売上CSVを、1クリックで1つのExcelレポートにまとめます。

- 文字コード（Shift_JIS／UTF-8）、列名の表記ゆれ、日付形式の違いを自動で吸収
- 月別×店舗の集計表とグラフ、商品ランキングを自動作成
- 重複や入力ミスは捨てずに「要確認」シートに一覧で出力
- デモ：形式の違う3店舗分のCSV（820件）を統合し、仕込んだミス6件をすべて検出 → [demo_report.xlsx](./csv-report-tool/demo_report.xlsx)

### 2. 整体院のランディングページ（HTML / CSS）
→ [デモを見る](https://inabe2929.github.io/portfolio/lp-sample/)　｜　[ソース](./lp-sample/)

- スマートフォン対応（画面下に予約ボタンを固定）
- 悩み → 選ばれる理由 → 流れ → 料金 → 声 → FAQ → 予約、の順で予約につなげる構成
- 外部ライブラリを使わず軽量

※ 店舗・口コミはすべて架空のものです。

## 対応できること
- Excel VBA・マクロ、Google Apps Script による業務の自動化
- Python によるデータ処理、ファイル変換、レポート作成
- LP・小規模サイトの制作と修正
