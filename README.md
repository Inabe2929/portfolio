# ポートフォリオ

Excel・CSV作業の自動化や、小規模なWebサイト制作を承っています。

## 制作サンプル

### 1. 売上CSV 統合・集計レポート自動作成ツール（Python）
→ [csv-report-tool](./csv-report-tool/)

形式の違う売上CSVを、1クリックで1つのExcelレポートにまとめます。

- 文字コード（Shift_JIS／UTF-8）、列名の表記ゆれ、日付形式の違いを自動で吸収
- 月別×店舗の集計表とグラフ、商品ランキングを自動作成
- 重複や入力ミスは捨てずに「要確認」シートに一覧で出力
- デモ：形式の違う3店舗分のCSV（820件）を統合し、仕込んだミス5件をすべて検出 → [demo_report.xlsx](./csv-report-tool/demo_report.xlsx)

### 2. 精密板金メーカーのコーポレートサイト（HTML / CSS / JavaScript）
→ [デモを見る](https://inabe2929.github.io/portfolio/corporate/)　｜　[ソース](./corporate/)

- サイト全体を製図用紙に見立てたデザイン。最初の画面で、板の切断から箱に折り上がるまでをSVGアニメーションで表示
- 材質・板厚・寸法・精度・ロット・見積回答日を最初に一覧、4工程、ご依頼の流れ、加工事例、会社概要
- 図面ファイルを添付できる見積フォーム

### 3. 食品店のネットショップ（HTML / CSS / JavaScript・Shopify 接続用）
→ [デモを見る](https://inabe2929.github.io/portfolio/shop/)　｜　[ソース](./shop/)

- 墨絵の山並みと川、縦書きの見出しで町の店の雰囲気を表現（画像ファイルなし、すべてSVG）
- 商品のカテゴリ絞り込み、送料無料までの残り金額が分かるかご
- カートと決済は Shopify Buy Button に接続する作り（デモではかごまで動作）。カード情報はサイトに残らない

### 4. 湖畔の宿のサイト（HTML / CSS / JavaScript・Canvas）
→ [デモを見る](https://inabe2929.github.io/portfolio/inn/)　｜　[ソース](./inn/)

- 写真を使わず湖をCanvasで描画。スクロールに合わせて夜→夜明け→昼→夕暮れと時刻が移る
- お部屋（窓からの景色つき）、お品書き、宿での一日、アクセス
- 部屋ごとの空室カレンダーとご予約フォーム

全体のトップ：[ポートフォリオ](https://inabe2929.github.io/portfolio/)

※ 2〜4の事業者・商品はすべて架空のものです。どのサイトも外部ライブラリなし、スマートフォン対応です。
