# 売上CSV 統合・集計レポート自動作成ツール

店舗やレジごとに形式がバラバラな売上CSVを、**1クリックで1つのExcelレポートにまとめる**ツールです。
毎月の「CSVを開いてコピペして集計」作業をゼロにします。

## できること
| 課題 | このツールの対応 |
|---|---|
| 文字コードが違う（Shift_JIS / UTF-8） | 自動判別 |
| 列名が違う（「日付」「売上日」など） | 表記ゆれを吸収 |
| 列の並び順が違う | 列名で判定するので順不同でOK |
| 日付形式が違う（2026/7/1・20260701・2026年7月1日） | すべて対応 |
| 数値に「,」「￥」や全角数字が混ざる | 自動で数値化 |
| 重複データ・入力ミス | 除外して「要確認」シートに一覧化（黙って捨てない） |

## 出力されるExcel
- **サマリー**：対象期間・件数・売上合計・ファイルごとの読み込み結果
- **月別×店舗**：クロス集計表と積み上げグラフ
- **商品ランキング**：販売数・売上・構成比
- **明細**：整形済みの全データ（フィルター付き）
- **要確認**：取り込めなかった行と理由（該当があるとタブが赤くなる）

## 使い方
1. `sample_input` フォルダ（または任意のフォルダ）に売上CSVを入れる
2. `レポート作成.bat` をダブルクリック
3. フォルダ内に `売上レポート_日時.xlsx` が作成される

コマンドで実行する場合：
```
py csv_report.py 入力フォルダ -o 出力.xlsx
```

## デモ
`py make_sample_data.py` を実行すると、わざと形式をバラバラにし、ミスを5件仕込んだ3店舗分（3か月）のCSVが作られます。
ツールはこの3ファイル・820件を統合し、仕込んだ5件をすべて「要確認」に出します。→ `demo_report.xlsx`

## 動作環境
Python 3.10以上、openpyxl（`py -m pip install openpyxl`）
※ ご要望があれば、Pythonなしで動く exe 版や Excel VBA 版にも対応します。

## カスタマイズ例
列名の候補（`COLUMN_ALIASES`）を追加するだけで、他システムのCSVにも対応できます。
集計の切り口（担当者別・曜日別など）の追加も可能です。
